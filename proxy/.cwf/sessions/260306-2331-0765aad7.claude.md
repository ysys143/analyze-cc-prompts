# Plan: Python Reverse Proxy for Claude Code API Message Capture

## Context

The `test_local_cc` project showed that setting `ANTHROPIC_BASE_URL` redirects Claude Code's API calls to a different server. That project pointed it at a local llama.cpp server, but the same technique can be used to create a **transparent reverse proxy** that:

1. Receives Claude Code requests
2. Logs/dumps the full request (system prompts, messages, tools)
3. Forwards to the real Anthropic API
4. Logs/dumps the response
5. Streams the response back to Claude Code

This gives us the ability to capture live messages from a real Claude Code session without breaking functionality.

## Target Directory

`/Users/jaesolshin/Documents/GitHub/analyze-cc-prompts/proxy/`

## Implementation

### Single file: `proxy.py`

A Python reverse proxy using `aiohttp` (async HTTP) that:

1. **Listens** on `http://localhost:8082`
2. **Catches** `POST /v1/messages` (the Anthropic Messages API endpoint)
3. **Dumps request** JSON to `dumps/YYYY-MM-DDTHHMMSS.sss-req.json`
4. **Forwards** to `https://api.anthropic.com/v1/messages` with all original headers (including `x-api-key`, `anthropic-version`, etc.)
5. **Handles streaming**: Since Claude Code uses `stream: true`, the proxy must:
   - Forward SSE chunks in real-time to Claude Code (no buffering delay)
   - Accumulate chunks in background and dump the full response to `dumps/YYYY-MM-DDTHHMMSS.sss-res.json`
6. **Passes through** all other endpoints (e.g., `/v1/models`) transparently

### Key Design Decisions

- **aiohttp** over Flask/FastAPI: lightweight, native streaming support, no extra ASGI server needed
- **Single file**: no package structure needed, just `pip install aiohttp` and run
- **Streaming passthrough**: use `aiohttp.StreamResponse` to forward SSE chunks as they arrive, zero buffering
- **Dump format**: same timestamp-based naming as `test_local_cc` dumps for consistency

### Usage

```bash
# Terminal 1: Start proxy
cd /Users/jaesolshin/Documents/GitHub/analyze-cc-prompts/proxy
pip install aiohttp
python proxy.py

# Terminal 2: Run Claude Code through proxy
ANTHROPIC_BASE_URL=http://localhost:8082 claude
```
