  실제로 Claude Code가 API 호출 시 보내는 HTTP 헤더에는 다음이 포함됩니다:

  ┌───────────────────┬────────────────────────────────┬────────────────────┐
  │       헤더        │         OAuth 인증 시          │  API Key 인증 시   │
  ├───────────────────┼────────────────────────────────┼────────────────────┤

  │                   │ 키)                            │ (환경변수)         │
  ├───────────────────┼────────────────────────────────┼────────────────────┤
  │ anthropic-version │ 2023-06-01                     │ 동일               │
  ├───────────────────┼────────────────────────────────┼────────────────────┤
  │ anthropic-beta    │ interleaved-thinking-... 등    │ 동일               │
  ├───────────────────┼────────────────────────────────┼────────────────────┤
  │ content-type      │ application/json               │ 동일               │
  ├───────────────────┼────────────────────────────────┼────────────────────┤
  │ User-Agent        │ Claude Code 버전 정보          │ 동일               │
  └───────────────────┴────────────────────────────────┴────────────────────┘
